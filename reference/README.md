# Original reference

`original_six_sensor_code.txt` is the original pasted six-channel Arduino sketch, preserved without modification. It uses AFMotor, color sensing and ultrasonic routines and has known issues documented during the initial review, including non-breaking spaces in source text.

This is historical input, not the supported firmware. Build `firmware/LineFollower/LineFollower.ino` instead. Keeping the file as `.txt` avoids confusing it with a second build target.
